# 🛒 Проект ShemelisList

Данное приложение было разработано в рамках учебного курса по мобильной разработке.

## Впечатления о курсе
Курс оставил исключительно положительные впечатления. Основные моменты, которые хотелось бы отметить:

*   **Все понятно:** Материал изложен очень доступно и последовательно, что позволило без проблем разобраться в процессе создания приложения.
*   **Интересно:** Обучение было захватывающим — было круто шаг за шагом видеть, как проект превращается в реальное работающее приложение на смартфоне.
*   **Практическая польза:** Процесс разработки от настройки первых экранов до сборки финального релизного файла с собственной иконкой и названием оказался очень познавательным.

Это был отличный опыт создания полноценного продукта «с нуля».
